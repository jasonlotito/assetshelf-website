Before you get started.

A library in your chosen folder
Imported files are copied. Your existing project files stay where they are.
AI starts off
New settings have automatic tagging and external AI tagging off. Enable the options you want in Settings → Tagging. Existing saved preferences are preserved.
For an existing library
Keep a verified backup before an upgrade. Quit AssetShelf before replacing the app in Applications.
For MCP clients
Reconnect after updating to refresh the tool definitions. Install a connection from Settings → Agents.

What’s in this release.

  • Less explanatory text in the inspector and sprite editor, with short tooltips for useful details.
  • Opt-in AI defaults and an automatic CLI model choice that shows the resolved model and reasoning effort.
  • Automatic DMG and ZIP release packaging, with signature, notarization-ticket and extracted-app checks.

Both architectures and package contents were verified. Physical Intel-Mac GUI acceptance remains a separate check.
