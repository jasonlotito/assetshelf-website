Bring the whole pack.

Drop files or folders from Finder, or use File Import. AssetShelf copies the media into your library and records the import as a group, so a new pack is easy to find again.

  • Import folders and supported media inside ZIP, 7z and TAR archives, including compressed TARs.
  • Content-based duplicate detection avoids adding another original when the same file is imported again.
  • Name an import as a collection, add it to an existing collection, or revisit it under Imports.
  • Drop Finder files directly onto a collection to import and organize in one action.

One file. More than one project.

A sound can live in Interface Sounds and your next game’s collection at the same time. Collections hold memberships, while tags, notes and source details stay with the asset.

  • Create, rename and merge collections; add or remove members without duplicating files.
  • Drag selected library assets onto a sidebar collection.
  • See collection information in the inspector; audio, image and mixed collections have distinct icons.
  • Copy source details from one collection and paste them onto another collection or selection.

Tidy the vocabulary, without AI.

Review similar tags together instead of cleaning thousands of names one at a time. Merge redundant labels, split useful phrases, and save rules for future tagging.

  • Suggested merges include singular/plural forms and minor spelling differences.
  • Search suggestions, select all matching results, apply them in bulk or dismiss them.
  • Split a phrase into tags; save common prefix/suffix rules and word-stripping rules.
  • Preview saved rules against existing tags before applying them; use tag history to undo changes.

And the details that make it useful.

Batch editing
Select all assets in the current results with Command-A. Apply tags, notes, source details, Favorites and Trash actions to the selection.
Undo that survives a restart
Trash and Favorites changes have persistent undo/redo history. Command-Z respects whether you are browsing assets or editing text.
Finder-style selection
Click for one tag, Command-click to add another, and Shift-click for a range. Search the sidebar’s tag list.
Keep the provenance
Record creator, source URL, license, pack and project details. Search that context and include it in exports.
Keep notes with the asset
Add your own usage notes. Notes and source details are shared across saved format variants.
Keyboard navigation
Use arrows, Page Up/Down, Home and End to browse. Copy files or reveal their originals in Finder.
