A backup you can recover from.

Create a backup, verify an existing one, or restore to a new location. The guided workflow checks library data and files rather than treating a completed copy as sufficient proof.

  • Manual backup and restore with recovery verification.
  • Choose a scheduled-backup destination, frequency and retention limit.
  • Older scheduled backups are pruned only after a new copy verifies successfully.
  • Background backups can run with AssetShelf closed while the Mac is awake and you are logged in.

See what needs attention.

Library Health collects missing or offline files, failed analysis or tagging, and incomplete source details into one reviewable list.

  • Inspect issue categories and jump directly to an affected asset.
  • Distinguish cloud-only files from missing files when provider metadata permits it.
  • Retry failed analysis and refresh the report when processing finishes.
  • Find missing creator, source URL or license details without opening every asset.

Your folder. Your storage choice.

Put the library where it works for you, including a folder managed by iCloud Drive or Dropbox. AssetShelf works with provider-managed files without requiring a separate cloud integration.

  • Working databases, thumbnails, waveforms and similarity indexes stay local to each Mac.
  • Shared library records and change history travel with the library alongside original media.
  • Cloud-only originals may need downloading before preview, analysis or conversion.
  • The Move command warns about other writers; moving a library does not reconnect other Macs automatically.

And the details that make it useful.

Source files stay where they are
Import copies media into the library. It never moves files out of a project that may still depend on them.
Recoverable organization
Persistent tag, Trash and Favorites history helps reverse mistakes without rebuilding your organization.
Shared-folder expectations
Changes can arrive before their media bytes. Wait for provider sync to finish and keep verified backups; this is not a live collaboration service.
Background scheduling
Missed scheduled backups catch up after login or wake. Sleeping or logged-out Macs cannot run the job.
Protect technical files
Internal library state is kept out of the ordinary media view. Per-Mac caches can be rebuilt from library data.
Move the complete library
Use the app’s move/backup tools. A partial folder copy or database copied while active is not a reliable recovery plan.
