AI is a choice, not a requirement.

New settings start with automatic tagging and external AI tagging off. You can enable local tagging, or explicitly enable a configured CLI/API provider.

  • On-device tagging uses filenames, Apple Vision image classification/OCR and Apple Sound Analysis.
  • Filename clues account for camelCase and other naming conventions.
  • Choose the Codex model and reasoning effort. Automatic displays the resolved model and sends that choice explicitly.
  • An optional direct API connection supports image and audio tagging; its usage is separate from CLI sign-in.

Find it. Get it. Put it to work.

Agents can search the same library using the same filters as the app, retrieve file paths and metadata, and export one file or a batch. They can also import files and edit the library.

  • Search names, tags, OCR, collections and measured image/audio properties.
  • Find visually or acoustically similar assets and inspect preview resources.
  • Import files, edit notes, tags, source details and properties, and manage collections.
  • Convert files, apply presets, export sprites and animations, and save sprite configurations.

Know what is happening.

The Activity window shows the current job, queued assets, completed tags and errors. It can stay open independently of the browser.

  • The current filename is visible without hovering; click it in the status bar to select the asset.
  • Pause or resume the queue and retry failed tagging when ready.
  • Model changes apply to the next file; the current job keeps its configuration.
  • A failing configured provider pauses with an error rather than silently switching providers.

And the details that make it useful.

Local MCP first
Clients connect on this Mac. No network-hosted MCP service or cloud account is required for the library connection.
Install without replacing other servers
Codex and Claude setup preserves existing client configuration. The connection can edit your library, so connect trusted agents.
Metadata and files
Agents can receive paths and resources, or export durable copies individually and in bulk.
CLI does not mean offline AI
The local Codex executable sends model inputs to its provider. Its audio tags infer from file inspection and signals; they are not literal listening.
Saved rules apply to future tags
Split and word-stripping rules clean up newly added tags as well as reviewed existing tags.
Reconnect after updates
Reconnect MCP clients after upgrading so they discover newly added tools and properties.
