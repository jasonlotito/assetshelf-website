Several formats, one asset.

A PNG and its WebP or JPEG variant belong to the same library entry. Tags, notes, source details, Favorites and collections stay shared.

  • Save converted files as variants or export copies only.
  • Switch the inspector preview between the original and its saved variants.
  • See format-specific size, dimensions and encoding details for the selected file.
  • Conversions never overwrite or automatically retag the original.

Images and audio, ready to travel.

Use native macOS encoders where supported, plus bundled WebP, MP3, Vorbis and Opus support. The app tests available outputs and presents compatible choices.

  • Image options include PNG, JPEG, WebP, TIFF, HEIC and other working macOS outputs.
  • Choose image quality, lossless options, transparency handling or a frame from an animated source.
  • Audio options include WAV, MP3, AIFF, M4A, FLAC, Ogg Vorbis and Opus, plus other supported containers.
  • Adjust compatible sample rate, channels, codec, bit depth or bitrate; available controls depend on format.

Save the settings you use again.

Name a conversion preset once, then apply it to selected assets from the right-click menu. The same presets are available to agents through MCP.

  • Save, update, rename and delete library-wide presets for images or audio.
  • Apply a preset to save variants without opening the conversion dialog.
  • Export copies to a chosen folder and remember the last destination.
  • Preserve filenames and add numeric suffixes to avoid overwriting existing files.

And the details that make it useful.

Batch conversion
Convert selections of up to 200 assets. Errors are reported per asset and cancellation removes incomplete outputs.
On-demand MCP conversion
An agent can request PNG output even when the original is another supported image format, or request WAV from supported audio.
Metadata travels with exports
Export manifests include source information and the settings used to create the files.
Format availability is checked
The exact list depends on macOS and the source. Unsupported or unreadable output is rejected instead of being attached as a variant.
Lossless has limits
Converting a compressed source to a lossless format cannot recover detail already discarded by the source encoding.
Full-resolution sprites
Sprite and animation exports complement ordinary file conversion. Keep sheet structure and frame settings with their source asset.
