The right size for the job.

Switch between grid, list and Finder-style gallery views. Enlarge grid previews for a visual scan, then use the inspector or gallery to examine a selected image.

  • Fit is the default whole-image view; Fill, Actual Size and Pixel Fit are additional choices.
  • Actual Size maps source pixels to display pixels. Pan oversized images within the existing view.
  • Pixel Fit uses pixel-aligned scaling for crisp small artwork.
  • The resizable inspector remembers its width and respects a manually hidden state.

Compare with a single moving divider.

Select two images to overlay them. Drag the center divider to reveal one on the left and the other on the right, keeping the comparison in one place.

  • Both images use the same selected scale mode.
  • Use Fill, Actual Size or Pixel Fit for the comparison.
  • At Actual Size, drag to pan both images together while keeping the divider independently draggable.
  • Swap sides when the comparison is easier to read the other way around.

More than width and height.

Local analysis reveals a palette, transparency, artwork bounds, animation information and image text. See measured values, correct useful metadata, and search using the same properties.

  • Brightness, contrast, saturation, palette complexity and dominant colors.
  • Transparency coverage, soft alpha, visible artwork size, outer padding and edge contact.
  • Orientation, aspect ratio and power-of-two dimensions.
  • Animation frame count, timing and loop metadata when the format provides it.

And the details that make it useful.

Colors you can reuse
Display HEX, RGB or CMYK values under their swatches. Click a color to copy the displayed value, or copy a palette image.
Readable transparent artwork
Preview backgrounds adapt so pale transparent icons remain visible. Pixel art keeps crisp edges.
Recognized image text
Apple Vision OCR makes image text searchable and presents it separately from tags.
Vector and design files
Preview static SVG/SVGZ, PSD composites, PDFs and PDF-compatible AI files. Larger rendered previews stay inside the app.
Rive playback
A bundled Rive runtime previews the default artboard interactively. Rive does not yet have raster thumbnails, palette analysis or visual similarity.
Respect the source
Property edits affect the library’s metadata, not the file’s pixels. An automatic-value reference is available for edited fields.
