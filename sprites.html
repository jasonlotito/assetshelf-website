Start with a suggestion. Finish with precision.

Local detection looks for transparent gutters and repeated edges. Dimension-based suggestions offer another starting point. Use guides and numeric controls to fit the artwork.

  • Set cell width, height, rows, columns, margins and horizontal/vertical gaps.
  • Drag around the first cell, then refine its horizontal and vertical guides.
  • Zoom the sheet, change the grid color or hide the grid while checking the artwork.
  • Select individual cells, ranges or the whole sheet; export up to 512 sprites per batch.

Use the names and boundaries you already have.

A matching XML or JSON atlas can supply exact sprite rectangles, including irregularly packed sheets. Preview the imported atlas before saving it to the asset.

  • Read Kenney/Sparrow TextureAtlas XML and TexturePacker/Aseprite JSON.
  • Search named sprites and select matching regions from the list or canvas.
  • PNG exports restore packed rotation and trimmed transparent padding.
  • Export sheet.png with compatible XML and JSON; an AssetShelf extension carries saved animation settings.

Make the frames move.

Select grid sprites, open Animation, and adjust the frame rate and loop setting. Reorder the frames in the strip and use that same order in the exported animation.

  • Preview at 1–60 FPS with play, pause, restart and looping controls.
  • Save named animation presets with grid, frame order, frame rate and looping.
  • Export animated GIF or lossless WebP using the preview settings.
  • Editor animation exports go to Downloads by default and copy the file to the clipboard.

And the details that make it useful.

Remember the setup
Save Configuration restores the layout, mode, selected frames, order, FPS and looping when the editor reopens.
Keep original pixels
Sprite crops use the original raster dimensions and preserve transparency. The source sheet stays unchanged.
Save several animations
Named presets let one sheet hold different sequences. Reopen, rename, update or delete them independently.
No AI required
Grid suggestions and atlas parsing are local. No AI provider is called to detect or export sprites.
Available to agents
MCP can inspect sheets, import metadata, save configurations and presets, and export selected sprites or animations.
Know the boundaries
Grid animation currently uses Grid mode. Irregular atlas regions export as named PNGs; vector and Rive sheets are not sliced.
